# AI Office - 가상 AI 오피스

월급 0원으로 AI 직원 6명을 운영하는 픽셀아트 스타일 가상 오피스 웹 서비스입니다.

## 기능

- **사무실 뷰**: 픽셀아트 스타일의 가상 사무실에서 AI 직원들이 일하는 모습
- **팀 채팅**: AI 직원들에게 지시를 내리고, 자동으로 협업하는 채팅 시스템
- **조직도**: AI 에이전트 기반 조직도 구성 (CEO, CTO, 팀별 구조)
- **사무실 편집**: 가구 배치, 사무실 꾸미기

## 실행 방법

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://localhost:5000` 접속

## 기술 스택

- **백엔드**: Python Flask
- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript
- **테마**: 픽셀아트 / 레트로 게임 스타일
